# AI Prompt Generator

A simple, free, and open-source prompt generator for social media, image generation, video creation, and creative projects.

## 🌐 Live Demo

https://winmi101.github.io/ai-prompt-generator/

## ✨ Features

- Facebook post prompt generator
- TikTok content prompt generator
- AI image prompt generator
- AI video prompt generator
- Gardening content prompt generator
- One-click prompt copying
- No registration required
- Runs completely in the browser

## 🚀 How to Use

1. Open the live website.
2. Select a prompt category.
3. Enter your topic.
4. Click **Generate Prompt**.
5. Copy the generated prompt.
6. Use it with your preferred AI tool.
