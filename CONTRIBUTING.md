# Contributing to AI Prompt Generator

Thank you for your interest in contributing!

Contributions of all kinds are welcome, including:

- New prompt categories
- Better prompt templates
- Bug fixes
- UI improvements
- Documentation improvements
- Accessibility improvements
- New language support

## How to Contribute

1. Fork this repository.
2. Create a new branch.
3. Make your changes.
4. Test your changes.
5. Commit your changes with a clear message.
6. Open a Pull Request.

## Good First Contributions

If you are new to open source, you can start with:

- Adding a new prompt category
- Improving wording in prompt templates
- Fixing spelling or grammar
- Improving the README
- Adding examples
- Improving mobile responsiveness

## Code Style

Please keep the project simple and beginner-friendly.

Use clear:

- HTML
- CSS
- JavaScript
- Variable names
- Commit messages

Avoid unnecessary dependencies unless they provide a clear benefit.

## Pull Requests

Please describe:

- What you changed
- Why you changed it
- How it improves the project

Screenshots are welcome for UI changes.

## Issues

Before opening a new issue, please check whether a similar issue already exists.

You can open an issue for:

- Bugs
- Feature requests
- Documentation improvements
- New prompt ideas
